# Future live milestone: disabled

Milestone 1 contains no signing/wallet/private-order implementation. `DisabledLiveAdapter.submit` always raises. Setting `LIVE_TRADING=true` cannot unlock a hidden path.

Before a later explicitly authorized milestone, require:

- Valid timestamped universe and original rule/fee vintages; frozen OOS protocol and no unresolved data defects.
- Positive execution-realistic after-cost expectancy with uncertainty, robustness and forward shadow evidence; review a failed candidate as a failure.
- Verified residence/account eligibility, platform terms and local legal requirements. India/Tamil Nadu eligibility is unresolved in this project. A public data response does not establish permission to trade. No VPN or proxy circumvention.
- Verified size/tick constraints, contract payout mechanics, current fee multipliers/rounding, authentication/signature scheme and token balances.
- Conservative correlation grouping, price/cash limits, kill switch, error/retry/idempotency rules, later-book latency tests, reconciliation, intratrade marking and backups.
- Key storage outside source control and audit logs; explicit small-capital cap and human activation; test refund/withdrawal/currency-conversion costs.

Polymarket official geoblock checks and Kalshi account eligibility must be performed at deployment time. This document is pending work; it is not a passed compliance checklist.
